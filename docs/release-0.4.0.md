# ApkShellext2 v0.4.0 — modern ZIP and SVG components

v0.4 removes the embedded SharpZipLib and SVG.NET source trees from the production project. APK, IPA and APPX containers use the .NET 10 `System.IO.Compression.ZipArchive` implementation through a bounded compatibility facade. Android VectorDrawable and SVG rendering use `Svg.Skia` 5.2.3 and SkiaSharp 4.148.0 through `VectorDrawableRender`; `System.Drawing.Bitmap` remains the Shell-facing boundary.

The package includes SkiaSharp and HarfBuzzSharp Windows native assets. It requires the x64 .NET 10 Windows Desktop Runtime and is framework-dependent. The v0.3 installation remains the rollback point until this branch has completed registered Shell, real APK icon, vector drawable, ZIP/IPA/APPX, cache and long-running Explorer tests.

The compatibility facade preserves shared read/write/delete file access, entry-size limits and deterministic disposal. Full package, native dependency and license manifests are generated by `tools/package.ps1`.
